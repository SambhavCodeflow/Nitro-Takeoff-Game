## 🎮 About

**Nitro Takeoff** is a single-file WebGL game set in an endless, glowing city. Race through traffic, drift around corners, hit ramps, and switch your Roadster into flight mode to soar over the skyline. Cause too much trouble and the police hunt you down. Lose them, grab the orbs, and try to reach **Mars**.

## ✨ Features

| | |
| --- | --- |
| 🏙️ **Endless neon city** | Procedurally generated blocks, ramps, props and glowing orbs |
| 🚗 **3 vehicles** | Supercar (drift king), Roadster (can fly), Robotaxi (tough cruiser) |
| 🛩️ **4 flight modes** | Hover, Jet, Booster and Hop for the Roadster. Thrusters stay on until you turn them off |
| 🚓 **Cops and heat levels** | Cause trouble and the chase begins. Get busted and you lose 30% of your score |
| 🔥 **Stunts and score** | Drifts, near misses, roof hops, backflips, frontflips, barrel rolls, big air, gold rings |
| ⏱️ **Checkpoints** | Race the timer and stack bonus points |
| 🚀 **Space flight** | Press `R` and your own car flies up into space. For 2 seconds it aims at Mars so you can pick **Earth, Moon or Mars**, then it jumps to **0.5c** (half the speed of light, 149,896 km/s) and arrives in about 5 seconds. Steer yourself or use the autopilot |
| 🌕 **Land and drive on the Moon and Mars** | Real ground driving with terrain, craters and rocks. Mars has friendly **aliens** (drive into one for +250) and a UFO. The Sun, Earth and Moon are in the sky. Mars gives +5000, the Moon +3000, coming home +2500 |
| 🔊 **Sound effects** | Jump, landing impacts, car crashes, tire squeal, police siren, nitro, flips, orbs, rings, checkpoints and the rocket launch. All synthesized in the browser, no audio files |
| 🌅 **Day, sunset, night and rain** | Change the mood of the city any time |
| 🎥 **4 camera views** | Chase, Far, Hood and Top |
| ⚙️ **Auto graphics** | Reads your GPU, CPU and RAM, runs a quick speed test, then picks Low, Medium, High or Ultra. It adapts while you play, and you can override it |
| 👥 **Tab-to-tab multiplayer** | Open the game in two tabs of the same browser and you will see each other's cars |
| 📱 **PC and phone** | Glossy on-screen touch buttons on mobile, fully remappable keys on desktop |

## 🕹️ Controls

### Keyboard

| Action | Key |
| --- | --- |
| Accelerate | `W` |
| Brake / reverse | `S` |
| Steer | `A` `D` or `←` `→` |
| Handbrake drift | `V` |
| Thruster jump (hold) | `Space` |
| Nitro (hold with gas) | `Shift` |
| Take off / land (Roadster) | `F` |
| Change fly mode | `G` |
| Climb / descend | `↑` or `E` / `↓` or `Q` |
| Backflip / Frontflip / Barrel roll (in air) | `Z` / `C` / `X` |
| Camera view | `B` |
| **Space flight** (in space: autopilot on/off, on a planet: take off) | `R` |
| Day, sunset, night | `T` |
| Rain on / off | `Y` |
| Reset car | `P` |
| Mute engine | `M` |
| Guide panel (remap keys, graphics) | `H` |

### Touch

Buttons appear automatically on phones and tablets. Every button has its name printed on it.

| Button | What it does |
| --- | --- |
| **LEFT / RIGHT** | Steer (left thumb) |
| **GAS / BRAKE** | Accelerate / slow down and reverse |
| **NITRO** | Speed boost (hold with GAS) |
| **DRIFT** | Handbrake slide |
| **JUMP** | Thruster jump |
| **FLY** | Roadster only. Tap once, thrusters stay on until you tap again |
| **MODE** | Roadster only. Switch Hover, Jet, Booster, Hop |
| **UP / DOWN** | Climb and descend while flying |
| **B.FLIP / F.FLIP / ROLL** | Stunts in the air |
| **Top icons** | Space flight (rocket), `?` guide, camera view, sound |
| **EARTH / MOON / MARS buttons** | Appear in space. Tap one to pick your destination |

The `?` icon opens a full guide that explains every button. Buttons that can't be used right now are faded.

### In space

| Action | Keyboard | Touch |
| --- | --- | --- |
| Turn | `A` `D` or `←` `→` | LEFT / RIGHT |
| Pitch up / down | `↑` `↓` (or `E` `Q`) | UP / DOWN |
| Throttle up / down | `W` / `S` | GAS / BRAKE |
| Full light speed (0.5c) | `Shift` (hold) | NITRO |
| Pick destination | `1` Earth, `2` Moon, `3` Mars | EARTH / MOON / MARS buttons |
| Autopilot on / off | `R` | FLY button or rocket icon |

Steering takes over from the autopilot. Planets slow you down automatically when you get close, so you can't crash into them. On the Moon or Mars: hold GAS to drive, press UP to take off, and press `R` to fly away.

## 💡 Tips

- Hold **Shift + gas** for nitro. Orbs and rings refill it.
- Mute the sound with `M` or the speaker icon.
- Pass close to traffic at high speed for **near-miss** points.
- Hit the **orange pads** for jumps and the **big white pad** for huge air.
- Fly low between buildings in the Roadster to earn **buzz** points.
- Tap the **rocket icon** (or press `R`). In space you have 2 seconds to tap **MOON**, **MARS** or **EARTH**. Follow the arrow markers, or let the autopilot do it.

## 📥 Download and run

The game is a single file, so there is nothing else to download.

1. Open [`nitro_takeoff.html`](nitro_takeoff.html) in this repo and click **Download raw file** (or use **Code → Download ZIP**).
2. Double-click the file. It opens in your browser. Play.

> The game loads [three.js r128](https://threejs.org/) from a CDN (with a backup CDN), so you need an internet connection when you open it.

Or just play online: **https://play.sambhavgames.workers.dev/nitro_takeoff**

## 🧰 Built with

- Plain **HTML, CSS and JavaScript**. No framework, no bundler
- **[three.js](https://threejs.org/)** (WebGL) for 3D graphics
- Inline **SVG** for icons, the speedometer and the car-select screen
- **BroadcastChannel API** for tab-to-tab multiplayer
- **Web Audio API** for the engine sound
